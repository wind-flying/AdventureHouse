# v0.20 Limited Market Economy（规划 · 待 v0.19 后启动）

## 状态

**未开始。** 前置：[v0.19-adventurer-activity-module-plan.md](./v0.19-adventurer-activity-module-plan.md) 食物日消耗核心完成后转入本迭代。

## 为何单独成篇

用户明确：干粮分级、市场流通、供粮激励、高级干粮作报酬等，属于 **市场/经济体系**，不应在 v0.19 里用「无限市场 + 孤立规则」硬凑。v0.19 只定义物品、营养、分配与接取加成；**有限库存与多方争抢** 在本篇闭环。

---

## 本次目标

1. 市场从「玩家专属、无限供给」升级为 **有限库存 + 可配置补货**
2. **干粮三档** 在 [`market.json`](../config/market.json) 挂牌，玩家与冒险者均可买卖（规则分层）
3. 冒险者参与市场采购时与玩家 **争抢同一库存池**
4. 深化 **供粮接取激励**（稀缺高粮任务更抢手）
5. **高级干粮** 作为任务报酬、赠礼、挂卖标的，形成流通叙事

---

## 依赖 v0.19 交付物

| v0.19 产出 | v0.20 用法 |

## 核心规则（草案）

### 有限库存

- `market.json` 扩展：`stock`、`restockPerDay` 或 `restockRule`
- 玩家买卖与冒险者分配 **共用库存**（或分池 config 化）
- 耗尽时：冒险者 fallback 顺序（店 → 等补货 → deficit）与 v0.19 对齐

### 干粮流通

- 三档干粮 `buyable` + `sellable`
- 玩家可囤货、供粮、挂卖（若后续有玩家挂卖则另议；v0.20 至少 NPC/系统回购）
- 高级粮：`giftValue` 高 → 赠礼；`basePrice` 高 → 市场锚点；可作 `rewards.items`

### 供粮与接取（深化）

- v0.19 已有：同模板，有供粮 > 无供粮
- v0.20：市场缺高粮时，「玩家供高粮」任务相对更稀缺、加成可再乘 scarcity 系数

### 冒险者市场行为

- 刚需/备货/囤货轮可从有限市场 offer 池购买
- 与全局贪心分配共用 [`foodScoring.ts`](../src/game/systems/adventurers/foodScoring.ts)（规划名）
- **卖货**（v0.18 预留压力）可在此版本接第一版：冒险者向市场/玩家回购出售 `carriedItems`

## 明确不做（首版）

- 多城镇 / 多市场
- 冒险者 P2P 交易
- 复杂拍卖行 UI

---

## 验收标准（规划）

- [ ] 干粮 listing 可买卖，库存有限且会耗尽
- [ ] 冒险者购买扣减与玩家购买同一库存（或文档约定分池）
- [ ] 补货规则可 config 化
- [ ] 供粮任务在稀缺环境下接取加成可感知
- [ ] 高级干粮可作为任务报酬进入流通
