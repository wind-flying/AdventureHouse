# v0.4 Resource Presentation

## 本次目标

建立第一版统一显示层，避免内部资源 id、状态值和认知层级直接从代码内部漏到玩家界面。

## 本次范围

- 为资源显示建立统一入口
- 为任务状态和认知层级文字建立统一入口
- 让 UI 中的资源偏好、库存、任务资源展示走同一套资源映射
- 让后续开发默认按“内部标识和展示内容分离”的标准继续写

## 明确不做

- 市场系统
- 建筑系统
- 主线任务系统
- 全量重构所有历史数据结构
- 一次性抽象出完整的显示框架

## 关键规则

- 内部资源 id 继续保留给程序使用，例如 `wood`、`food`
- 玩家看到的资源名和图标统一从资源显示层获取
- UI 不应直接把内部值拼给玩家看
- 状态文本与认知层级文本也尽量集中管理，不散落在各个渲染函数里
- 旧数据结构可以暂时保留，但新增显示逻辑默认走统一入口

## 验收标准

- 冒险者偏好不再直接显示内部资源 id
- 任务卡片、库存和资源下拉项都走统一资源显示入口
- 任务状态与认知层级的显示文字不再散落在 UI 文件内部
- 构建仍然可以通过

## 风险和待定问题

- 这版只是第一步，后续如果要做更复杂的物品显示，可能还需要单独的展示模型
- 故事文本虽然已经接到统一资源显示入口，但还没有形成更完整的文本上下文层

## 跨版本待处理

- 后续市场、建筑、礼物等系统新增时，资源展示应继续复用本版建立的显示层，不要重新各写一套
- 如果后面资源字段进一步增多，可以考虑把更多玩家侧文案从逻辑层中剥离到专门的显示模型
