# v0.5 Adventurer Personality

## 本次目标

为冒险者建立第一版隐藏人格轴，让他们接任务不再只是“有偏好资源的人随机来接”，而是开始基于性格做出不同选择。

## 本次范围

- 给冒险者设计一组少量但有效的人格轴
- 明确人格轴与“冒险属性”的分层，不混为一谈
- 明确这些人格轴分别影响哪些行为判断
- 明确玩家看到的是标签和印象，而不是原始数值
- 为后续代码实现准备配置结构和显示规则

## 明确不做

- 完整战斗属性系统
- 礼物系统
- 关系值深化
- 主线事件分支
- 一次加入十几二十种性格维度
- 直接把人格数值展示给玩家

## 关键规则

- 人格轴是隐藏值，范围暂定为 `-1 ~ 1`
- 玩家默认看不到原始数值，只能通过印象、倾向标签和行为结果反推人物特征
- 人格轴主要服务于“接不接任务、偏好什么任务、合作是否稳定”这类行为判断
- 冒险能力属性和人格属性分层：
  - 冒险能力属性：以后影响任务成败、耗时、伤势、收获
  - 人格属性：当前优先影响任务选择、风险偏好、合作倾向
- 第一版人格轴数量要少，优先选择能直接驱动玩法差异的维度

## 第一版人格轴建议

### 1. 勤勉

- 高：更愿意接稳定、重复、补货类任务
- 低：更不容易长期稳定接基础活

### 2. 勇敢

- 高：更愿意接高风险、长耗时、未知回报的任务
- 低：更偏向安全任务

### 3. 逐利

- 高：更看重报酬
- 低：更容易因为别的原因接活，例如兴趣、顺路、人情

### 4. 社交

- 高：更容易和玩家建立熟悉感，也更容易受关系影响
- 低：更封闭，不容易靠简单互动拉近关系

### 5. 审慎

- 高：更规避低把握度、高不确定性任务
- 低：更可能贸然尝试

### 6. 求知

- 高：更偏向调查、探索、传闻、异常事件类任务
- 低：更倾向实用型任务

### 7. 纪律

- 高：更稳定、更守约、更适合长期合作
- 低：更随性，合作波动更大

### 8. 韧性

- 高：失败后恢复更快，更容易继续接活
- 低：受挫后更容易回避类似任务

## 玩家侧展示原则

- 玩家不直接看到：
  - `勤勉 = 0.73`
  - `勇敢 = -0.24`

- 玩家看到的是归纳后的倾向描述，例如：
  - 做事认真
  - 更偏稳妥
  - 对高报酬很敏感
  - 喜欢新鲜见闻
  - 不太好接近

- 同一人物的标签不需要一次全公开，可以继续受认知层级影响：
  - 听闻：只给模糊传闻
  - 见过：只知道这个人和一条印象
  - 打过交道：开始看到偏好和少量倾向
  - 熟客：给更多稳定标签
  - 信赖：才开放更深层的动机信息

## 人格轴与当前玩法的第一轮对接

第一批优先接入这些行为：

- 任务接取权重
  - 是否喜欢对应资源
  - 是否愿意接该报酬水平
  - 是否排斥该耗时和风险

- 合作稳定性
  - 有些人更适合长期补货
  - 有些人更适合偶尔承担特殊任务

- 结果反馈可解释性
  - 玩家开始能从“谁接了什么任务”反推出人格差异

## 目前不建议直接加入的人格维度

下面这些概念不是不合理，而是当前版本对玩法帮助不如前八项直接：

- 条理
- 礼法
- 本真性
- 处事圆融
- 实验精神
- 想象力

后续如果系统变复杂，可以再从这些方向扩展。

## 验收标准

- 冒险者人格属性在文档层定义清楚
- 每个属性都明确影响什么行为
- 玩家侧展示方式定义清楚
- 能和当前“认知层级”系统兼容
- 后续代码实现时不需要重新推翻这套命名

## 风险和待定问题

- 人格轴太少可能导致人物差异仍不明显
- 人格轴太多又会让配置和调试负担迅速上升
- `逐利` 和 `勤勉`、`审慎` 与 `勇敢` 之间可能会出现解释重叠，后续实现时需要控制权重
- 当前任务接取权重里的调参值仍属于第一版临时参数，后续要继续收敛成更稳定的任务特征模型或配置层

## 跨版本待处理

- 后续仍需要补“冒险能力属性”设计，避免所有差异都压到人格轴上
- 人格标签如何随认知层级逐步公开，后续需要和 UI 一起细化
- 如果后续加入礼物系统，需要明确哪些人格轴更容易被什么礼物间接影响
- 后续应从“单人接任务”扩展到“自由组队 / 固定队伍”模型，让任务效率、安全性和反馈完整度都受队伍结构影响
- 后续任务耗时不应继续只是固定倒计时，而应逐步拆成“固定耗时 + 可变耗时 + 延迟回报”模型，例如赶路、等待、战斗、返程分别影响玩家何时得知结果
- 后续应先补足任务行为特征维度，再让人格映射到这些特征，避免多个不同人格长期共同挤在“风险 / 性质”这几个输入上

## 结果记录

- 已为当前冒险者配置补充第一版隐藏人格轴，范围按 `-1 ~ 1` 存储
- 日常任务接取已从“随机 + 资源偏好”升级为“资源偏好 + 人格权重”
- 当前接取权重已开始受勤勉、勇敢、逐利、社交、审慎、求知、纪律、韧性影响
- 玩家侧仍不直接看到原始数值，而是通过性格标签间接了解人物倾向
- 第一版任务接取调参值已集中提升到 [taskBoard.ts](/home/windflying/Code/AdventureHouse/src/game/systems/taskBoard.ts) 顶部，避免继续散落成神秘数字
- 旧的任务耗时规则、人格标签阈值、初始状态常量和 UI 通知时长也已开始按同样方式显式化，避免历史参数继续埋在逻辑内部
- 测试阶段的冒险者池已扩展到 8 个，并改为“设计目标型命名”，避免当前原型文本被误认为正式角色设定
- 承接逻辑已从“所有空闲人物都参与排序”改成“先过个人意愿阈值，再在候选池中竞争”，如果当前没有人愿意接，任务会继续挂在板上
- 风险偏好已改成非对称处理：高危排斥明显强于低危无聊，避免“喜欢危险”和“害怕危险”在公式上被错误地写成镜像关系
- 任务性质相关的求知偏好也已显式改成非对称：厌恶异常的排斥强于爱新鲜者面对普通任务时的轻微无聊
