# v0.23 Act1 工作台信息架构

## 本次目标

把 Act1 开局从「标签墙 + 总览摘要」改成一块始终可见的工作台，让玩家落地就能完成：发补货委托 → 进下一天 → 看人和故事。

## 本次范围

- 重构主界面壳层：侧栏、右侧状态、百科入口、主内容分区
- 工作台四块：今日目标、一键发补货委托、在镇人物条、故事轨
- 市场 / 库存 / 厨房制作收进「救急」
- 消息板 / 日志 / 存档 / 百科收进「查阅」或「设置」
- 百科保持可开，但首屏不拦截决策

## 明确不做

- 不改市场、补货、食物等经济后台公式
- 不改 Act1 任务白名单与解锁链
- 不做 Act2 信息架构
- 不处理存档导入 XSS 等 P0 债务

## 关键规则

- 工作台是默认落地页，四块在常见桌面首屏同时可见
- 一键发补货委托走现有 `createQuest`，使用当前建议数量和酬金，不要求先去市场
- 救急与查阅默认不是第一决策路径
- 百科对话框默认关闭，只在玩家主动打开时出现

## 验收标准

1. 打开游戏后，工作台上能同时看到今日目标、一键发补货、在镇人物、故事轨
2. 市场 / 库存 / 制作不与工作台平级
3. 消息板 / 日志 / 存档不在第一决策路径
4. 百科不挡住第一次发委托

## 结果记录

- 默认页改为 `workbench`
- 左侧主入口只保留「工作台」和「救急」
- 查阅默认折叠：委托、人物、消息板、日志、百科
- 设置默认折叠：存档
- 故事轨收到工作台内，点击展开全文
- 在镇人物点击后打开详情，不需要先翻人物页
