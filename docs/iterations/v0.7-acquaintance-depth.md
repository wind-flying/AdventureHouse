# v0.7 Acquaintance Depth

## 本次目标

把当前过于粗糙的冒险者认知层级细化成一个更像“逐步认识镇上居民”的过程，而不是见几次面就直接熟识。

## 本次范围

- 将冒险者认知层级从 3 层扩展为 5 层
- 引入接触点数，用于逐步推进认知关系
- 让冒险者页按认知层级逐步公开信息
- 保持当前玩法简单，不引入正式关系值系统

## 明确不做

- 礼物系统
- 正式关系值数值条
- 定向委派
- 书信互动
- 更复杂的人际网络

## 关键规则

- 认知层级调整为：
  - 听闻
  - 见过
  - 打过交道
  - 熟客
  - 信赖
- 第一次接下任务，只能说明“见过本人”
- 完成过任务后，才算真正打过交道
- 后续需要多次往来，才会逐步成为熟客和信赖对象
- 玩家看到的信息量应随认知层级逐步开放，而不是一次性全给

## 验收标准

- 冒险者不再因为少量接触就直接变成熟识
- 冒险者页能体现更细的认知层次
- 不同层级公开的信息量有明显区别

## 风险和待定问题

- 当前接触点仍主要来自接任务和完成任务，来源还比较单一
- 后续如果加入送礼、书信、传闻事件，需要一起接入认知推进

## 跨版本待处理

- 后续可以把“信赖”再接到定向委派、特殊反馈和关系事件
- 后续可加入更多非任务接触来源，例如店内互动、传闻事件、书信往来
- 冒险者页筛选区后续应固定在内容区顶部，不随下方卡片列表一起滚动；任务页筛选区也应按同一原则统一处理

## 结果记录

- 冒险者认知层级已从 3 层扩展为 5 层：听闻 / 见过 / 打过交道 / 熟客 / 信赖
- 已加入接触点数，默认通过“接任务 +1、完成任务 +1”推进认知
- 冒险者页现在会按层级逐步公开信息，而不是一两次接触就直接看到大部分内容
- 动机信息已后移到“信赖”层级，性格标签也会随认知加深逐步增加
- 冒险者页已加入认知层级、人物状态、置顶分组筛选
- 玩家现在可以手动置顶人物，页面会自动分成“置顶人物 / 其他人物”两组显示
