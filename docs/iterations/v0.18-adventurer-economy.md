# v0.18 Adventurer Economy

## 本次目标

让冒险者钱包参与日常循环，并作为接取公式的经济压力修正层。

## 本次范围

- `src/game/systems/economy/adventurerEconomy.ts`
- 任务完成向冒险者支付报酬
- 每日生活费扣款
- `taskAcceptance.ts` 增加 `economicAdjustment` 与缺钱时的 greed 加成
- `gifting.ts` 用真实 `carriedMoney` 感知替换占位常量

## 明确不做

- 债务、义务、关系例外接取
- 劳动力市场竞争
- 冒险者每日食物消耗与自主活动（见 [v0.19-adventurer-activity-module-plan.md](./v0.19-adventurer-activity-module-plan.md)，**待实现**；有限市场见 [v0.20-limited-market-economy-plan.md](./v0.20-limited-market-economy-plan.md)）

## 跨版本待处理

- **`adventurerDailyLivingCost` 为占位**：当前每日从 `carriedMoney` 扣固定数额，与食物 / 市场 / 店铺无真实关联；后续由 v0.19 `dailyFoodNeed` 替换；v0.20 再将市场改为有限库存（见 v0.20 规划）。
- 来店零售（v0.17）与每日运维语义尚未统一：零售是可选消费，不是刚性需求；合并时需避免重复购买 / 重复扣款（见 v0.19 规划缺口表）。

## 关键规则

- 经济修正作为 v0.10 之上的额外状态层，不重写默认人格骨架
- 缺钱降低兴趣阈值，宽裕轻微抬高阈值

## 验收标准

- `carriedMoney` 会随任务报酬、生活费、来店消费变化
- 缺钱冒险者更容易接低门槛任务

## 结果记录

- 已落地钱包循环与接取/赠礼经济感知
