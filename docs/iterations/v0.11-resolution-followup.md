# v0.11 Resolution Follow-up

## 文档用途

这份文档用于记录：哪些内容已经明确不应继续塞在 `v0.9` 或 `v0.10`，而应在 `v0.11` 处理。

它不是当前要立刻实现的清单，而是为了避免：

- `v0.9` 做着做着又回去补体验层细节
- `v0.10` 做着做着又被结果层拖偏
- `v0.11` 开始时还要重新整理前两版到底留下了什么

## 预计主目标

在 `v0.9` 的正式结算骨架和 `v0.10` 的接任务骨架稳定后，补“结果层”和“解释层”。

换句话说：

- `v0.9` 解决“系统到底怎么算”
- `v0.10` 解决“谁会接任务，以及玩家如何看懂人物意向”
- `v0.11` 解决“结果如何更像真实冒险，并且玩家如何理解这些结果”

## 计划处理项

- 结果可解释性增强
- 部分成功 / 部分失败
- 伤病与长期代价
- 线索质量、线索来源更复杂地影响结果
- 任务结果与消息回传的更细耦合
- 对结算结果的 UI 解释补强
- 更成熟的测试矩阵与内容校验工具

## 不在这版优先处理

- 组队
- 冒险者之间关系
- 自由贸易市场
- 冒险者自主经济循环
- 完整地图
- 长期命运闭环

这些应继续保持在更后面的版本中，不应挤占当前 `1.0` 主线节奏。
