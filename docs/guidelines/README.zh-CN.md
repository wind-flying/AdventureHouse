# 设计守则目录

这个目录只放长期可复用的设计守则。

它和 `docs/iterations/` 的区别是：

- `docs/iterations/`
  - 记录某个版本当时做了什么、没做什么、为什么这么收口
- `docs/guidelines/`
  - 记录后续持续适用的配置思路、编写规则和设计边界

适合放进这个目录的内容：

- 配置文件怎么写
- 哪些字段属于正式长期结构
- 文本、数值、标签应该如何分层
- 后续扩内容时应复用什么，而不是重复硬写

不适合放进这个目录的内容：

- 某个版本一时的范围判断
- 临时测试样例说明
- 只对单次重构有效的迁移记录
