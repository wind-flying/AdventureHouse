# 冒险者模板设计守则

## 文档用途

这份文档用于约束后续对以下配置的改动：

- `config/adventurers/`
- `config/names/`
- `config/text/`

目标不是解释某次版本改了什么，而是明确：

- 冒险者模板应该怎么写
- 哪些内容应该复用
- 哪些文本和数值不该硬绑在一起
- 哪些区间参数可以写，哪些不该瞎填

## 当前正式分层

### 1. 结构与数值配置

放在：

- `config/adventurers/`

这里负责：

- 模板 `id`
- 是否固定角色 / 普通模板
- 名字池引用
- 原型标签
- 引介标签
- 偏好
- 人格基准值
- 能力基准值
- 后续正式启用时的区间参数

这里不负责长期正文编写。

### 2. 可复用名字素材

放在：

- `config/names/`

这里负责：

- 姓氏表
- 名字表
- 后续地区风格名字池

规则：

- 名字池是复用素材，不应在每个冒险者模板里重复手写
- 如果多个模板共用一套名字风格，应通过 `namePoolId` 引用

### 3. 世界观正文文本

放在：

- `config/text/`

当前主要包括：

- `adventurer-introductions.json`
- `config/text/adventurers/anchors.json`
- `config/text/adventurers/archetypes.json`

这里负责：

- 名称文本
- 称号文本
- 动机文本
- 印象文本
- 传闻文本
- 接触来源文本

规则：

- 改文本时，优先只改 `config/text/`
- 改结构、标签、数值时，优先只改 `config/adventurers/`
- 不要把大量正文重新写回执行代码

## 模板分类守则

### 固定角色模板

例如开场锚点角色。

特点：

- 主要服务叙事身份
- 通常不进入普通随机池
- 可以带固定名字
- 可以只有极小波动，甚至暂时无波动

### 普通生成模板

例如“河滩搬运工”“旧路打听者”“采石老手”。

特点：

- 不是某一个具体人
- 是一个人物原型类别
- 会在接触事件中生成实例
- 应优先依赖名字池和文本池，不要把它写成单一固定人物

## 文本守则

### 同模板不应只有唯一正文

如果一个普通模板会重复生成，就不应只有唯一一条：

- `motive`
- `impression`
- `rumor`

当前允许在 `config/text/adventurers/*.json` 中写成数组：

```json
{
  "adventurers": {
    "quarry-hand": {
      "motive": ["文案1", "文案2", "文案3"],
      "impression": ["文案1", "文案2"],
      "rumor": ["文案1", "文案2", "文案3"]
    }
  }
}
```

规则：

- 普通模板应优先使用文本池
- 固定角色可以暂时只保留单条正文
- 文本池内的几条文本应表达同一原型，不要写成互相冲突的人设

### 文本变体的职责

文本变体用于制造：

- 同模板不同人的细微差异
- 世界观质感
- 重复生成时的可读性

它不负责制造：

- 完全不同的人格原型
- 完全不同的能力定位
- 互相矛盾的背景设定

这些应由模板本身区分，而不是靠文本池硬撑。

## 数值守则

### 基准值是模板核心，不是临时参考

当前模板中的：

- `personality`
- `capabilities`

应理解为该模板的正式基准值。

它们表达的是：

- 这类人通常是什么样
- 不是某次随机结果恰好长成什么样

### 区间参数不能拍脑袋填

后续如果启用：

- `personalityRanges`
- `capabilityRanges`

这些字段时，必须遵守：

- 先有明确设计理由，再写数值
- 不能只因为“想让它看起来更随机”就随手填
- 区间应服务模板原型，而不是破坏模板原型

至少要回答：

- 哪些轴是这个模板的稳定主场
- 哪些轴允许明显波动
- 哪些轴只允许轻微浮动
- 低区和高区是否应对称

### 当前默认规则

在模板没有正式写区间前，生成层可以继续使用统一默认振幅。

这代表：

- 生成模型可以先升级
- 但模板专属区间不能在没有设计结论时提前硬塞

### 非对称原则

后续如果区间和分布继续细化，不应默认做成左右镜像。

原因：

- 这个项目已经确认很多关系是非对称的
- 某些模板可以“通常不差，但偶尔特别强”
- 也可以“通常中等偏上，但掉下去会很快”

所以后续允许：

- 某区间变化平缓
- 超过某阈值后概率快速下降
- 高区和低区不对称

但这类规则必须在正式设计后再落数值，不应边想边写死。

## 复用守则

以下内容优先复用，不要在每个模板里重复硬写：

- 名字池
- 接触来源文本
- 原型标签
- 任务吸引标签
- 同原型的文本变体池

如果一个内容明显会在多个模板中反复出现，就应优先考虑抽成公共素材，而不是复制粘贴。

## 改配置时的最低检查

每次新增或修改一个普通冒险者模板，至少检查：

1. 它是不是一个“人物原型”，而不是把某个具体人误写成普通模板
2. 它是否有清晰主场，而不是和别的模板长期重叠
3. 它的名字是否来自合适的名字池
4. 它的文本是否至少能表达稳定原型，而不是只有空壳标签
5. 如果加了区间参数，这些区间是否有明确设计理由

## 当前阶段结论

当前更推荐的工作顺序是：

1. 先把模板基准值写对
2. 再把文本池写出最小可读差异
3. 再补名字池和标签复用
4. 最后才补模板专属区间和更复杂分布

不要反过来：

- 先写大量复杂区间
- 再回头想这个模板到底是什么人

那样只会把随机做复杂，不会把原型做清楚。
